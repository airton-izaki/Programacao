1 - HTML

HTML (HyperText Markup Language) é a linguagem de marcação padrão utilizada para criar e estruturar páginas web. Desenvolvido por Tim Berners-Lee no início dos anos 1990, o HTML é a espinha dorsal de praticamente todos os sites da internet, permitindo que conteúdos como textos, imagens, vídeos e links sejam organizados de forma lógica e acessível nos navegadores.

A principal função do HTML é estruturar o conteúdo de uma página web. Ele define a hierarquia e a disposição dos elementos visíveis ao usuário, como títulos, parágrafos, listas, tabelas, formulários e botões. O HTML atua como um "esqueleto" do site, enquanto outras tecnologias, como CSS (Cascading Style Sheets) e JavaScript, cuidam da apresentação visual e da interatividade, respectivamente.

Quando um navegador (como Chrome, Firefox ou Safari) carrega uma página, ele interpreta o código HTML e o renderiza na tela, seguindo as instruções de marcação para exibir cada elemento corretamente.

    Principais Características do HTML
  1. Linguagem de Marcação, não de Programação
    O HTML não é uma linguagem de programação, pois não possui lógica de decisão ou loops. Ele é composto por tags (etiquetas) que "marcam" o conteúdo para indicar ao navegador como ele deve ser exibido.
  2. Estrutura Hierárquica (em Árvore)
    Os elementos HTML são organizados em uma estrutura de árvore, com um elemento raiz (<html>) que contém outros elementos aninhados, como <head> e <body>. Essa hierarquia é essencial para a correta interpretação e renderização.
  3. Uso de Tags e Atributos
    As tags são os blocos de construção do HTML, escritas entre colchetes angulares, como <p> para parágrafos e <h1> para títulos. As tags podem ter atributos que adicionam informações extras, como id, class, src (para imagens) ou href (para links).
  4. Semântica
    O HTML moderno (a partir do HTML5) dá grande ênfase à semântica, ou seja, ao uso de tags que descrevem o significado do conteúdo, como <header>, <nav>, <article>, <section> e <footer>. Isso melhora a acessibilidade e o SEO (otimização para mecanismos de busca).
  5. Compatibilidade com Outras Tecnologias
    O HTML trabalha em conjunto com CSS e JavaScript. O CSS controla a aparência (cores, fontes, layout), enquanto o JavaScript adiciona comportamento dinâmico (animações, validações, requisições). Além disso, o HTML é compatível com APIs como canvas, geolocalização e armazenamento local.
  6. Acessibilidade
    Com o uso adequado de atributos como alt (em imagens), aria-label e tags semânticas, o HTML permite que pessoas com deficiências visuais ou motoras utilizem leitores de tela e outros recursos assistivos, tornando a web mais inclusiva.
  7. Extensibilidade e Evolução Constante
    O HTML está em constante evolução, com novas versões e especificações sendo lançadas pelo W3C (World Wide Web Consortium) e pela WHATWG. O HTML5, lançado em 2014, trouxe suporte nativo a áudio, vídeo, gráficos vetoriais e armazenamento offline, entre outros recursos.
  8. Simplicidade e Facilidade de Aprendizado
    Uma das maiores vantagens do HTML é a sua curva de aprendizado suave. Qualquer pessoa pode começar a criar páginas web com poucas linhas de código, o que o torna a porta de entrada ideal para o desenvolvimento web.
  9. Responsividade e Design Adaptável
    Embora a responsividade seja mais associada ao CSS, o HTML suporta o uso de meta tags como viewport, que ajudam a ajustar a página para diferentes tamanhos de tela (mobile, tablet, desktop).

O HTML é muito mais do que um conjunto de tags — é o alicerce sobre o qual toda a web moderna é construída. Sua função essencial de estruturar informações, combinada com características como semântica, acessibilidade e integração com CSS e JavaScript, faz dele uma ferramenta indispensável para qualquer pessoa que deseje atuar no universo do desenvolvimento web. Dominar o HTML é o primeiro e mais importante passo para construir experiências digitais ricas, funcionais e acessíveis.
